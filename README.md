# DATASYSTEM--AI
Um projeto de dados com o foco principal em recomendações ,sugestões de decisão,voltada para o setor de varejo e comercial!
Transformada em uma plataforma para facilitar a visualização do projeto.

# FUNCIONAMENTO
Temos a tecnologia de Machine Learning especialista para treinar com dados corporativos ,de vendas,desistencias e cancelamentos de compra.
Após o treinamento e leitura desses dados ,podendo ser enviados pelo usúario em formato PDF, CVS, a machine learning treinada com os dados de desistencias e compras, 
e ter o treinamento do setor de como funciona o setor ,problemas enfretados ,soluções propostas do setor em específico, a machine learning especializada irá recomendar 
soluções para o problema de converter compras canceladas ou desistencias para compras efetuadas.

Para visualização a integração de uma IA se mostra efetiva na arquitetura, visto que a velocidade de gerar aspectos de visualização é bem efíciente o que agrada ao projeto, dito isso
para dashnoards e visualização a inteligência artificial ficou com esse papel.
