# DATASYSTEM--ML
O DATASYSTEM-ML é uma solução baseada em Machine Learning voltada para análise preditiva e detecção de anomalias em dados corporativos. O projeto emprega técnicas de aprendizado supervisionado com foco em modelos de Regressão para identificar desvios nos padrões de vendas e antecipar métricas cruciais de negócio, como taxas de cancelamento e desistência de compras.

# FUNCIONAMENTO
O sistema processa e interpreta históricos financeiros e operacionais para monitorar oscilações mês a mês em relação a linhas de base operacionais (como um teto anual de referência de desistências).

Através da modelagem por Regressão, o projeto permite:

1.Predição Contínua: Mapear tendências de vendas, desistências e cancelamentos com base no histórico de dados.
2. Detecção de Anomalias:Identificar comportamentos discrepantes ou desvios fora da margem esperada de um período para o outro.



# Tecnologias usadas
Python (Linguagem base para manipulação e estruturação do projeto)
Scikit-Learn (Construção, treinamento e validação dos modelos de Machine Learning)
Aprendizado Supervisionado(Técnicas de modelagem orientadas a dados rotulados)
Modelos de Regressão(Algoritmos focados em previsão quantitativa contínua) - SVR

# DATASYSTEM--ML
DATASYSTEM-ML is a Machine Learning-based solution designed for predictive analysis and anomaly detection in corporate data. The project employs supervised learning techniques focusing on regression models to identify deviations in sales patterns and forecast critical business metrics, such as cancellation and purchase abandonment rates.

# HOW IT WORKS
The system processes and interprets historical financial and operational data to monitor month-over-month fluctuations against operational baselines (such as an annual reference ceiling for abandonments).

Through regression modeling, the project enables:

1. Continuous Prediction: Mapping trends in sales, abandonments, and cancellations based on historical data.
2. Anomaly Detection: Identifying outlier behaviors or deviations falling outside the expected range from one period to the next.

# Technologies Used
Python (Core language for project manipulation and structuring)
Scikit-Learn (Construction, training, and validation of Machine Learning models)
Supervised Learning (Modeling techniques based on labeled data)
Regression Models (Algorithms focused on continuous quantitative forecasting) - SVR
